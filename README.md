# Italiano L2

Percorso adattivo di italiano come lingua seconda (A1–C1) per studenti stranieri. Funziona tutto nel browser, senza server e senza costi.

| Pagina | Per chi | Indirizzo |
|---|---|---|
| Area insegnante | l'insegnante | https://profserenadegaspari.github.io/italianoL2/insegnante.html |
| App degli studenti | gli studenti, tramite il link di invito | https://profserenadegaspari.github.io/italianoL2/studenti.html |
| Pagina iniziale | chiunque | https://profserenadegaspari.github.io/italianoL2/ |
| Demo con dati di esempio (non collegata dalla pagina iniziale) | chi la riceve | https://profserenadegaspari.github.io/italianoL2/demo.html |

## Come funziona

1. L'insegnante apre l'area insegnante e crea gli studenti (pagina **Studenti**).
2. Per ogni studente preme **Link** e gli manda il link di invito su WhatsApp o per email.
3. Lo studente apre il link: l'app si prepara sul suo dispositivo con il suo nome. Può aggiungerla alla schermata Home.
4. Una volta a settimana lo studente preme **Invia i miei progressi** nella pagina *Io* e manda il file all'insegnante.
5. L'insegnante importa i file nella pagina **Studenti** e vede progressi, errori e testi.

Per far arrivare allo studente un commento a un testo, un cambio di livello o la richiesta di un test, basta rimandargli il link di invito: i suoi progressi restano.

I dati restano nei browser di insegnante e studenti: in questo repository ci sono solo l'app e i dati finti della demo. Conviene scaricare ogni tanto un backup dalle **Impostazioni** dell'area insegnante.
